# EcoSort AI - Complete Project Index

## Project Overview

EcoSort AI is a production-ready waste classification and environmental sustainability platform built with Next.js, TypeScript, and machine learning algorithms. It combines advanced AI techniques with environmental science to help users make informed waste disposal decisions while tracking their environmental impact toward sustainable development goals.
